# MemoryRiver

MemoryRiver 是一个记忆呈现 demo：在屏幕中用一条黑色幕布上的粒子河流，尽可能直观地展开一个人的记忆。

它不是普通日记回放，也不是单纯的数据分析页。当前 demo 的目标是先做出“一眼惊艳”的记忆空间：河流承载时间与经历，物品代表关键事件，小鱼代表用户在时间流中的方向感。

## 当前 Demo

当前仓库只保留一个可运行原型：

- `particle_river_demo.html`

直接用浏览器打开该文件即可查看粒子河流效果。

## 核心体验

- 黑色幕布中出现一条会流动的粒子河流，形成记忆长河的第一视觉印象。
- 关键事件会被压缩成可识别的物品 icon，半沉在河流中。
- 鼠标悬停物品时，物品从河流中浮起，表示记忆被主动触达。
- 点击物品后，后续会展开该事件的详细记忆内容。
- 滚轮用于浏览时间，正向表示时间向前，反向表示时间回溯。

## 视觉隐喻

- 河流：代表时间、外部经历、人生阶段和事件流动。
- 粒子：代表记忆碎片的流动感，让河流具有生命感和沉浸感。
- 物品：代表关键事件，是用户可以点击进入的记忆锚点。
- 小鱼：代表用户自己在时间流中的状态与方向。

## 数据设定

产品底层采用分层记忆结构：

- 第一层：记忆单元，以单个事件为颗粒度，从用户表达中直接抽取。
- 第二层：阶段聚合，把分散事件按人生阶段和标签组织成桶。
- 第三层：影响模式，由 AI 从聚合结果中观察和归纳行为、状态、偏好等外显影响。
- 第四层：沉淀结论，由 AI 总结价值观、自我认同、人格特征、长期目标等更深层信息。

第一层来自用户直接表达；第三层和第四层是 AI 侧观察。它们可以共用结构，但不能混在同一层，因为颗粒度不同。
