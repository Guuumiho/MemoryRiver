# MemoryRiver

MemoryRiver 是一个记忆展现产品

把一个人的人生经历，幻化成一条可以被看见、被回溯、被点击的记忆长河。

## 产品愿景

MemoryRiver 想回答的不是“你记录了什么”，而是“你是谁，是怎样一步步变成现在的你”。

它把用户的经历、阶段、情绪、影响和沉淀，组织成一套可视化的记忆空间，让用户在有限屏幕里尽可能完整地看见自己的人生轨迹。

## 核心体验

- 用户可以把自传、日记、聊天记录等内容导入进来，也可以在和 AI 对话中持续补充新的记忆。
- 系统会把这些内容组织成分层记忆结构，从单个事件逐步汇聚为阶段、影响和沉淀。
- 用户在一条会流动的记忆河流中浏览自己的经历，像在时间里行走。
- 关键记忆会被压缩成物品锚点，用户可以悬停、触达、点击它们，进入具体事件。
- 小鱼代表用户自己，随着时间方向变化而切换状态。

## 视觉语言

- 河流代表时间、经历与人生流向。
- 粒子代表记忆碎片与流动感。
- 物品代表关键事件。
- 小鱼代表用户在时间中的自我状态。

## 记忆结构

MemoryRiver 采用四层记忆结构：

1. 记忆单元
   - 单个事件级别的信息。
   - 来自用户的直接表达。

2. 阶段聚合
   - 把相近事件按标签和阶段组织起来。
   - 用来形成更大的时间段与主题块。

3. 影响模式
   - 从多个事件中归纳用户的外显变化。
   - 关注行为、情绪、习惯、偏好和应对方式。

4. 沉淀结论
   - 从更长跨度中提炼稳定的自我认知。
   - 关注价值观、身份认同、长期目标和人格特征。

这四层可以共用一套数据结构，但不能混成同一层，因为颗粒度和用途不同。

## 产品价值

- 让用户快速看见自己的人生轮廓。
- 让零散记忆变成有结构的空间体验。
- 让“想不起来的经历”重新浮现出来。
- 让用户看到自己如何被事件塑造，也如何在事件中成长。
